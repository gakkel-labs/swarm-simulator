### Héritée du 2026-05-21
Tous les items #1 à #14 du snapshot précédent restent valides. **Attention :** les références `file:line` peuvent avoir changé suite aux refactors structurels — vérifier par symbole (ex: `toVec3` est maintenant dans `WorldStateBuilder`, pas dans `SwarmObserverImpl`).

Voir [`tech-debt-2026-05-21.md`](tech-debt-2026-05-21.md) pour le détail.

### Nouvelles observations

#### A. `SwarmObserverImpl` démarre toujours son broadcaster dans le constructeur
`SwarmObserverImpl.java` — `scheduleAtFixedRate` est appelé directement dans le ctor. Avec l'injection de l'executor désormais en place (résout partiellement #11 du snapshot précédent), une méthode `start()` séparée découplerait construction et démarrage. Utile pour des tests d'intégration qui veulent construire l'objet sans déclencher le scheduler.

#### B. `WorldStateBuilder` utilise `System.currentTimeMillis()` non-injectable
`WorldStateBuilder.build()` capture le timestamp via un appel direct à `System.currentTimeMillis()`. Pour des tests déterministes (vérifier une séquence d'événements), un `Clock` injectable (`java.time.Clock`) serait utile en v0.2 ou quand on ajoutera des tests d'intégration end-to-end (#1 du snapshot précédent).

#### C. `predator-0` toujours hardcodé — déménagé
`WorldStateBuilder.toPredatorState()` — l'ID prédateur reste hardcodé. C'est l'item #12 du snapshot précédent, juste relocalisé.

## Findings d'audit rejetés en cours de consolidation

Conservés pour mémoire — n'est **pas** un to-do, c'est de l'analyse à archiver.

| Finding initial | Raison du rejet |
|---|---|
| `Agent.create()` jamais utilisée → supprimer | Factory de convenance utilisée par ~30 tests. Suppression = 30 sites à mettre à jour pour zéro gain. |
| `TriggerSource` paramètre ignoré → retirer | Placeholder volontaire pour v0.2 (CLI, scenario file) — documenté dans [ADR-0004](adr/0004-target-placement-operator-triggered.md). |
| `wallForce()` re-implémente `normalize()` | Faux positif : `(nx, ny, nz)` est déjà unitaire, le `1/dist` est une force inverse-distance volontaire. Un commentaire a été ajouté pour éviter une future confusion. |
| `BoidsRules.steer(agent, neighbors)` 2-arg jamais appelé → supprimer | Faux positif : appelé en interne par le 3-arg (composition utile). Action retenue : passage en package-private. |
| `SwarmObserverImpl.toProtoType()` switch sans `default` → exception silencieuse | Java 21 refuse de compiler un switch expression exhaustif si une valeur est ajoutée — pas de risque silencieux. Action retenue : `default → throw` défensif (1 ligne, no harm). |
| `ping.proto` non-versionné → aligner sur `gakkel.{service}.v1` | Ping est un test de connectivité, pas un contrat métier qui évoluera. L'incohérence apparente avec `swarm_observer.proto` est documentée dans [`02-grpc-contract.fr.md` §5.5](../documentation/02-grpc-contract.fr.md). |

**Leçon transverse :** sur cet audit, ~38 % des findings étaient des faux positifs ou des décisions intentionnelles documentées. Un audit fournit des pistes à valider en lisant le code, pas des actions à appliquer aveuglément.
