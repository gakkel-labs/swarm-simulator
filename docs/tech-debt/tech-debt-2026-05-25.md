## Remaining debt

### Inherited from 2026-05-21
All items #1 to #14 of the previous snapshot are still valid. **Careful:** the `file:line`
references may have changed after the structural refactors — check by symbol (e.g. `toVec3` is
now in `WorldStateBuilder`, not in `SwarmObserverImpl`).

See [`tech-debt-2026-05-21.md`](tech-debt-2026-05-21.md) for the details.

### New observations

#### A. `SwarmObserverImpl` still starts its broadcaster in the constructor
`SwarmObserverImpl.java` — `scheduleAtFixedRate` is called directly in the constructor. Now that
the executor is injected (which partly solves #11 of the previous snapshot), a separate `start()`
method would decouple building and starting. Useful for integration tests that want to build the
object without starting the scheduler.

#### B. `WorldStateBuilder` uses a non-injectable `System.currentTimeMillis()`
`WorldStateBuilder.build()` takes the timestamp with a direct call to `System.currentTimeMillis()`.
For deterministic tests (checking a sequence of events), an injectable `Clock` (`java.time.Clock`)
would help in v0.2, or when end-to-end integration tests are added (#1 of the previous snapshot).

#### C. `predator-0` still hard-coded — moved
`WorldStateBuilder.toPredatorState()` — the predator ID is still hard-coded. This is item #12 of
the previous snapshot, just moved.

## Audit findings rejected during the consolidation

Kept for the record — this is **not** a to-do, it is analysis to archive.

| First finding | Why it was rejected |
|---|---|
| `Agent.create()` never used → remove | Convenience factory used by ~30 tests. Removing it = 30 places to update for zero gain. |
| `TriggerSource` parameter ignored → remove | Deliberate placeholder for v0.2 (CLI, scenario file) — documented in [ADR-0004](../adr/0004-target-placement-operator-triggered.md). |
| `wallForce()` re-implements `normalize()` | False positive: `(nx, ny, nz)` is already a unit vector, the `1/dist` is a deliberate inverse-distance force. A comment was added to avoid future confusion. |
| 2-argument `BoidsRules.steer(agent, neighbors)` never called → remove | False positive: called internally by the 3-argument one (useful composition). Action kept: made package-private. |
| `SwarmObserverImpl.toProtoType()` switch without `default` → silent exception | Java 21 refuses to compile an exhaustive switch expression if a value is added — no silent risk. Action kept: defensive `default → throw` (1 line, no harm). |
| `ping.proto` not versioned → align on `gakkel.{service}.v1` | Ping is a connectivity test, not a business contract that will evolve. The apparent inconsistency with `swarm_observer.proto` is documented in [`02-grpc-contract.md` §5.5](../02-grpc-contract.md). |

**Cross-cutting lesson:** in this audit, ~38 % of the findings were false positives or documented
deliberate decisions. An audit gives leads to check by reading the code, not actions to apply blindly.
